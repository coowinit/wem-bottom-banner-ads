# WEM Bottom Banner Ads

轻量级 WordPress 响应式底部横幅广告插件。适用于展会活动、促销及临时通知，兼容经典主题和支持 `wp_footer()` 的现代主题。

## 功能

- **安全默认值**：首次安装广告关闭；启用后默认仅在首页显示（`is_front_page()`），也可选择全站显示。
- **双设备图片**：从 WordPress 媒体库选择 PC 与手机图片；PC 推荐 1200×200px、手机推荐 750×220px，允许其他尺寸，不裁切原图。
- **响应式**：手机断点 640px，最大宽度 1200px，图片等比例缩放。手机图片可留空，自动使用 PC 图片。
- **广告链接**：后台设置目标 URL、是否新窗口打开、ALT 文字；URL 留空则图片不可点击。
- **轻量交互**：底部滑入动画、关闭按钮；关闭记录保存在当前标签页的 `sessionStorage`。更换图片或链接后，新广告会重新展示。
- **独立资源**：无 jQuery、Bootstrap、外部 CDN 等依赖；使用插件内 SVG 关闭按钮。

## 安装

1. 在 WordPress 后台进入「插件 → 安装插件 → 上传插件」，上传本插件 ZIP。
2. 激活后可在「插件 → 已安装插件」中点击本插件的「设置」链接，或进入「设置 → WEM Banner Ads」。
3. 从媒体库选择 PC/手机广告图片、填写目标链接，确认显示范围。
4. 勾选「启用底部横幅广告」并保存设置。
5. 打开网站首页验证。若站点使用 WP Rocket、Cloudflare 或其他页面缓存，修改后按需清理缓存。

> 默认 **不启用** 广告。PC 图片为必填展示条件：即使开启广告，没有 PC 图片时也不会输出空白广告。

## 技术说明与维护

- 使用 WordPress Settings API 存储独立配置，使用图片附件 ID 而非硬编码的媒体 URL。
- 按需注册前端资源，以 `wp_footer` 输出 HTML；依赖主题正确调用 `wp_head()`、`wp_footer()`。
- 通过 `<picture>` 选择手机图片；CSS 与 JavaScript 与主题隔离。
- 使用 `esc_url()`、`esc_attr()`、`sanitize_text_field()` 等确保输出及设置合理过滤。
- 固定横幅会覆盖页面底部内容。若站点使用固定客服按钮、Cookie 提示、聊天窗口，请检查层级及重叠。
- `sessionStorage` 记忆范围是当前标签页会话，不是跨设备或长期记忆；禁用存储时仍可临时关闭。
- 改图片文件内容但保留同一个附件 ID 和链接时，关闭记录不会自动重置；如需强制刷新，可重新选择新附件。
